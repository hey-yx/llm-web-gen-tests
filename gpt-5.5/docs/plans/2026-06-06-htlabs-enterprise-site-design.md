# HTLabs Enterprise Site Design

## Goal

Create three static visual directions for 上海宏途数创科技有限公司 so the user can compare brand tone before choosing a final corporate website direction.

## Audience

The site targets enterprise decision makers, partners, and potential clients looking for reliable digital transformation, business system, data visualization, and intelligent application delivery services.

## Content Model

Each variant uses the same core information so the comparison focuses on brand expression rather than content changes:

- Hero statement with company name and digital innovation positioning
- Core capabilities: digital consulting, software systems, data governance and visualization, intelligent applications
- Service scenarios: brand digitization, management systems, data dashboards, process optimization
- Advantages: restrained design, reliable delivery, grounded technology, long-term cooperation
- Contact call to action without fabricating phone numbers or addresses

## Variant 1: Dark Premium Tech

This direction uses deep ink-blue surfaces, subtle radial light, precise line work, and sharp contrast. It should feel advanced, stable, and suitable for a technology company serving serious enterprise clients.

## Variant 2: Light Minimal Business

This direction uses a warm off-white background, black typography, restrained blue accents, and crisp whitespace. It should feel clean, transparent, efficient, and easy for traditional business clients to trust.

## Variant 3: Oriental Whitespace Premium

This direction uses paper-like tones, ink-blue text, muted gold accents, and generous rhythm. It should feel calm, cultivated, refined, and more brand-led than technical.

## Technical Constraints

The project is a no-dependency static website. Each page is standalone HTML with embedded CSS so it can be opened directly from the file system.

## Verification

Use `node tests/check-static-site.js` to confirm required files and core copy exist.
